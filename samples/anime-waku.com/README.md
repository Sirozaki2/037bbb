# Anime-Waku — รอ HTML ตัวอย่าง

ตรวจ https://anime-waku.com/ และ https://www.anime-waku.com/ ได้ HTTP 403 จาก Cloudflare รวมถึง Chrome ใน sandbox จึงยังไม่มี provider ที่ยืนยันโครงสร้างได้

บันทึกจาก Chrome บนเครื่องที่เข้าได้เป็น Webpage, Complete พร้อมโฟลเดอร์ไฟล์ประกอบ โดยไม่ต้องเปิด DevTools:

1. `home.html`: หน้าแรกที่มีหมวดและรายการ
2. `search.html`: ผลค้นหาที่พบอย่างน้อยหนึ่งเรื่อง พร้อมคำค้นในชื่อไฟล์หรือข้อความกำกับ
3. `series.html`: หน้ารายละเอียดที่แสดงรายชื่อตอน
4. `episode.html`: หน้าตอนที่กดเล่นได้ ถ้ามีหลายเซิร์ฟเวอร์ให้ระบุว่าตัวไหนเล่นได้
5. ถ้ามี: ตัวอย่างพากย์ไทย, ซับไทย, หนัง และหน้ารายการหน้าที่สอง

เก็บชื่อโฟลเดอร์ `_files` คู่กับ HTML และระบุ URL ต้นฉบับของแต่ละหน้า หาก Chrome ไม่เก็บไว้ใน HTML
ไม่ต้องส่ง cookies, รหัสผ่าน หรือข้อมูลบัญชี; HTML ใช้ตรวจตัวอ่านได้ แต่ยังต้องตรวจลิงก์วิดีโอสดและทดสอบในแอปอีกครั้ง
